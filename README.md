# Engine Atlas

Interactive 3D exploration of seven parametric engines: turbofan, turbojet, turboprop, turboshaft, V8, inline-four, and rotary. Inspect components, reveal cutaways, animate mechanisms, and scrub continuously from a complete assembly to individual pieces.

## Run locally

Install Node.js 22.13 or newer with npm (Node 24 was used for this handoff). Use a modern browser with WebGL2 and hardware acceleration. Internet access is needed to install dependencies.

```sh
npm ci
npm run dev:local
```

Open the localhost address printed by Vite. No API key, AI subscription, database, or cloud account is required to run the local application. All engine geometry is generated by the included TypeScript code.

Local command aliases avoid the original hosted scripts' Bash/GNU utility requirements. Validation was performed on Linux; native Windows and macOS have not been tested.

## Commands

| Command | Purpose |
| --- | --- |
| `npm run dev:local` | Local development with hot reload |
| `npm run build:local` | Compile browser assets and the Cloudflare Worker into dist |
| `npm run start:local` | Serve a production build locally |
| `npm run test:engines` | Check all seven models, disassembly, and mechanisms |
| `npm run test:local` | Build and run existing HTML/component checks |
| `npm run build` | Original bounded hosted build, requires Bash and GNU timeout |
| `npm run install:ci` | Original Linux hosted installation helper |

This is a React/Vinext application. Use its server instead of opening source files in a browser. The production output includes a Worker and is not a static-only website.

## Explore

- Choose an engine from the picker.
- Select, hide, or isolate component groups or individual pieces.
- Drag **Explode engine** between **Assembled** and **Every piece**.
- Choose Inventory or Radial, adjust spacing, or play the reversible loop.
- Use cutaway and mechanism animation. Flow is available for turbine engines.

These are original educational reference models, not manufacturer CAD or service instructions. Motion illustrates mechanism relationships, not a calibrated thermodynamic or structural simulation.

## Continue with a coding agent

Open this directory in Codex. Root `AGENTS.md` provides project guidance. Three skills are installed in `.agents/skills/`, each with `SKILL.md` and `agents/openai.yaml` metadata:

Use $engine-explosion to improve spacing while preserving exact reassembly.
Use $engine-validation to verify changes across all seven engines.

## Repository and deployment

The ZIP contains the complete source snapshot without dependencies, build caches, credentials, or Git history. `EXPORT-MANIFEST.json` records the source commit and checksums. To start your own Git repository:

```sh
git init
git add .
git commit -m "Import Engine Atlas"
```

The portable export removes the original account-specific Site ID from `.openai/hosting.json`. Keep this file because Vite imports its logical binding fields. No replacement ID is needed locally. For Sites hosting, connect your own account and register or select your own Site. Other hosting requires a compatible Worker deployment or a deliberate runtime adaptation.

To export another committed snapshot, run `python3 scripts/export-repository.py /absolute/path/engine-atlas-repository.zip`. Python 3 and Git are needed only for that export command.

Third-party packages retain their own licenses. Keep `vendor/shadcn-tailwind-4.13.0.LICENSE.md` with its stylesheet. This handoff does not assign a new open-source license to the project.
